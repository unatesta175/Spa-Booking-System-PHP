## 💡 Image Specs

- **Format:** PNG or JPG
- **Size:** 800x600px (recommended, will auto-resize)
- **Quality:** High resolution
- **Style:** Professional spa/wellness photos

After adding all images, you should have:
- [ ] 1 logo file (`lunara-new-logo.png`)
- [ ] 14 service category files (`sc1.png` through `sc14.png`)
